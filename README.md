# History 3D — Educational Platform (Concept)

This is a landing page concept for an educational platform dedicated to the ancient world. 

> ⚠️ **Note:** Currently, this is a **static frontend prototype** (just the main page). The interactive maps, 3D reconstructions, and buttons are not functional yet.

## Current Status

* **Header & Navigation:** Visual layout only.
* **Hero Section:** Introduction to the concept with a static "Select a City" button.
* **City Cards:** Visual previews for the Acropolis, Rome, and Giza (clickable elements are placeholders).

## Future Plans

* Implement interactive maps for each ancient city.
* Integrate 3D models and reconstructions.
* Add educational historical data.

## Tech Stack

* HTML5
* CSS3
* JavaScript (Placeholder setup)

## How to View

Simply clone the repository and open `index.html` in your browser to see the layout.
